Build-to-learn session on: $ARGUMENTS

Design a 15–25 minute lab in labs/<CODE>/<slug>/ that forces the student to understand the concept (if `me.md` says they don't code, make it a spreadsheet or pen-and-paper build instead):
1. One-paragraph goal + the rule from the material (cite the file).
2. A starter file with TODOs and 3–5 test cases taken from the course's own examples/worksheets (expected outputs included), runnable with `python3`.
3. They write the code; you review like a senior dev, but the feedback is about the concept.
4. Finish with 2 exam-style questions answered WITHOUT the code.
Examples: accounting trial-balance checker, math function shift/reflect plotter, Excel SUMIF/COUNTIF clone, programming branch tracer, essay linter (contractions, "you", questions, thesis last in intro), management SWOT generator for their project in `me.md`.
Log it (type "study") and commit.
